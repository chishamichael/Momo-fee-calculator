# Mobile Money Fee Calculator

A simple React-based Mobile Money Fee Calculator for calculating transaction fees for MTN, Airtel, and Zamtel.

## Features

- Select between MTN, Airtel, and Zamtel
- Network-specific interface colors
- Network branding
- Enter a transaction amount
- Automatically calculate the transaction fee
- Automatically calculate the total amount
- View the fee structure for each network
- Input validation
- Responsive design for smaller screens

## Technologies Used

- React
- Vite
- JavaScript
- HTML
- CSS
